# 오늘의 주문

- 주문 제목: 오늘 날짜 성경 범위 선택 화면
- 날짜: 2026-08-11
- 작업 상태: 완료

## 오늘 만들 기능

관리자가 미리 정한 오늘 날짜의 성경 범위를 사용자가 성경 범위 입력창에서 선택할 수 있는 임시 화면을 만듭니다.

## 수정할 화면

- Bible Hunter 성경 범위 입력 화면

## 구체적인 요청

- 성경 범위 입력창을 클릭하면 오늘 날짜와 미리 정한 성경 범위를 보여줍니다.
- 오늘의 범위 아래에 `직접 입력하기` 선택지를 함께 보여줍니다.
- 오늘의 범위를 선택하면 입력창에 자동으로 반영합니다.
- 직접 입력하기를 선택하면 기존 입력창에 자유롭게 입력할 수 있습니다.
- 이번 단계는 2026년 8월 11일 임시 데이터로 화면과 선택 동작만 확인합니다.

## 이번에는 하지 않을 작업

- 관리자용 한 달치 성경 범위 입력 화면
- Supabase 저장 및 조회
- 다른 날짜의 실제 데이터 관리

## 완료 조건

- 입력창을 클릭하면 오늘 날짜의 추천 범위와 직접 입력 선택지가 보입니다.
- 두 선택지가 각각 입력창 자동 반영과 직접 입력으로 동작합니다.
- 기존 다음 단계 진행 기능이 유지됩니다.
- lint와 build가 통과합니다.

## Codex 작업 결과

- 성경 범위 입력창에 오늘 날짜의 추천 범위와 직접 입력 선택지를 표시했습니다.
- 추천 범위를 누르면 입력창에 자동 반영되고, 직접 입력하기를 누르면 자유 입력으로 전환됩니다.
- 이번 확인용 데이터는 `2026-08-11 · 창세기 11장 1–9절`로 지정했습니다.

## 변경한 파일

- `npm.cmd run build`: 통과
