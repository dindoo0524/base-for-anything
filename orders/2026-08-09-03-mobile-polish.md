# 오늘의 주문서

- 주문 제목: v2.0 모바일 사용성 보강
- 날짜: 2026-08-09
- 작업 상태: 완료

## 오늘 만들 기능

v2.0의 기능은 유지하면서 휴대폰에서 읽기, 글쓰기, 메뉴 이동, 삭제가 더 편하고 안전하도록 화면을 다듬습니다.

## 구체적인 요청

- iPhone 노치와 하단 홈 인디케이터 안전영역을 반영합니다.
- 작은 화면에서 제목, 카드, 프로필, 버튼이 겹치지 않게 합니다.
- 하단 메뉴 네 항목을 한 줄에 같은 크기와 간격으로 보여줍니다.
- 삭제 버튼을 잘못 누르면 바로 삭제되지 않도록 한 번 확인합니다.
- 입력 중 화면 확대와 가로 넘침이 생기지 않게 합니다.

## 이번에는 하지 않을 작업

- 가족 초대와 웰컴 화면
- 데이터베이스 구조 변경
- 새로운 게시판 기능
- 디자인 컨셉 변경

## 완료 조건

- 320px부터 일반적인 모바일 너비까지 주요 화면이 자연스럽게 줄어듭니다.
- 주요 버튼의 터치 영역이 충분합니다.
- 삭제 전에 확인 문구가 나타납니다.
- lint와 build가 성공합니다.

## Codex 작업 결과

가족 게시판의 기능과 데이터베이스 구조는 유지하고 모바일 사용성만 보강했습니다. 상단 노치와 하단 홈 인디케이터 안전영역, 작은 화면의 여백과 줄바꿈, 터치 반응을 다듬었습니다. 하단 메뉴는 소개·가족글·글쓰기·내 정보가 한 줄에 같은 크기와 간격으로 표시됩니다. 입력창에 포커스가 있으면 모바일 키보드와 겹치지 않도록 하단 메뉴가 잠시 숨겨집니다. 글 삭제 전에는 확인창이 나타납니다.
