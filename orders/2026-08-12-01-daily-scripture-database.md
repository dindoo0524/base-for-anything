# 오늘의 주문서

- 주문 제목: 날짜별 QT 본문 DB 연결과 입력 화면 개선
- 날짜: 2026-08-12
- 작업 상태: 완료

## 오늘 만들 기능

2026년 8월과 9월의 날짜별 QT 본문을 Supabase에 저장하고, 로그인한 사용자가 오늘 본문을 자연스럽게 입력받도록 화면을 개선합니다.

## 작업하는 이유

현재 성경 범위 선택창이 다음 버튼을 가리고 쉽게 닫히지 않으며, 본문과 대시보드가 2026년 8월에 고정되어 있어 9월부터 사용할 수 없기 때문입니다.

## 구체적인 요청

- Supabase에 날짜별 본문을 저장하는 `daily_scriptures` 테이블을 추가합니다.
- 제공받은 생명의삶 2026년 8월 31건과 9월 30건을 저장합니다.
- 오늘 날짜의 본문을 DB에서 조회해 성경 범위 입력창에 자동으로 채웁니다.
- 사용자는 필요한 경우 자동 입력된 본문을 직접 수정할 수 있습니다.
- 입력창을 가리는 큰 선택 팝업을 제거하고 단순한 오늘 본문 안내로 바꿉니다.
- 대시보드의 연도와 월, 날짜 수가 현재 날짜에 맞게 자동으로 바뀌게 합니다.
- 나민숙님이 이후 한 달치 본문을 직접 추가할 수 있는 SQL 예시와 안내를 작성합니다.
- 실행 코드에서 과거 localStorage 사용이 없는지 확인하고, QT 데이터는 Supabase만 사용합니다.
- 로그인 상태는 Supabase 세션 쿠키로 유지합니다.

## 이번에는 하지 않을 작업

- 관리자용 본문 입력 화면
- 외부 QT 홈페이지 자동 수집
- 과거 브라우저 데이터 이전
- 회원과 댓글 권한 구조의 추가 변경

## 완료 조건

- 2026년 8월 12일 본문 `겔 39:1~10`을 DB에서 조회할 수 있습니다.
- 8월과 9월 본문 61건이 migration에 포함됩니다.
- 오늘 본문이 성경 범위 입력창에 자동 반영되고 직접 수정할 수 있습니다.
- 선택 팝업이 다음 버튼을 가리지 않습니다.
- 9월에는 대시보드와 작성 날짜가 자동으로 9월로 바뀝니다.
- 브라우저를 닫았다 다시 열어도 기존 Supabase 로그인 세션을 사용할 수 있습니다.
- lint와 build가 통과합니다.

## Codex 작업 결과

- `daily_scriptures` 테이블과 로그인 사용자 조회 RLS 정책을 추가했습니다.
- 제공받은 2026년 8월 본문 31건과 9월 본문 30건을 날짜별 seed로 작성했습니다.
- 오늘 날짜의 본문을 Supabase에서 불러와 성경 범위에 자동 입력하도록 변경했습니다.
- 입력창을 가리던 선택 팝업을 제거하고 작은 오늘 본문 안내 카드로 교체했습니다.
- 자동 입력된 본문을 사용자가 직접 수정하거나 오늘 본문으로 다시 적용할 수 있습니다.
- 대시보드의 연도, 월, 날짜 수를 기기 현재 날짜 기준으로 자동 계산하도록 변경했습니다.
- 실행 코드에 localStorage 사용이 없음을 확인했습니다. 로그인은 기존 Supabase 세션 쿠키 방식으로 유지됩니다.
- 다음 달 본문을 SQL Editor에서 추가하고 확인하는 안내 문서를 작성했습니다.
