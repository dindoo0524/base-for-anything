# 오늘의 주문서

- 주문 제목: 우리 가족 말씀편지 화면 만들기
- 날짜: 2026-08-09
- 작업 상태: 완료

## 오늘 만들 기능

기본 화면을 우리 가족 말씀편지 컨셉으로 바꾸고 목록에서 글의 상세 내용을 읽을 수 있게 합니다.

## 작업하는 이유

큐티 묵상과 가족에게 전하는 편지가 단톡방에서 묻히지 않고 같은 주소에 차곡차곡 모이게 하기 위해서입니다.

## 수정할 화면

- `/` 공개 목록
- `/entries/[id]` 공개 상세 화면
- `/admin` 새 글 작성 화면

## 구체적인 요청

- 프로젝트 이름과 소개 문구를 우리 가족 말씀편지에 맞게 바꿉니다.
- 목록에서는 제목, 본문 미리보기, 작성 날짜를 보여줍니다.
- 목록의 글을 선택하면 상세 화면에서 전체 본문을 읽습니다.
- 관리 화면의 문구를 큐티와 편지 작성에 맞게 바꿉니다.
- 크림색, 짙은 자주색, 올리브색의 차분한 편지지 분위기로 조정합니다.

## 반드시 유지할 기능

- 공개 조회
- 관리자 로그인
- Supabase 글 저장
- 최신순 목록
- Supabase가 없을 때 설정 안내
- 모바일 가독성

## 이번에는 하지 않을 작업

- 사진
- 카테고리와 검색
- 댓글과 반응
- 수정·삭제
- 회원가입

## 완료 조건

- 목록과 상세 화면의 역할이 구분됩니다.
- 관리자 화면에서 기존과 동일하게 제목과 본문을 저장할 수 있습니다.
- 가족 말씀편지 컨셉과 문구가 공개·관리 화면에 일관되게 보입니다.
- lint와 build가 성공합니다.

## 작업 후 사용자가 확인할 내용

- 공개 목록에서 글 미리보기와 날짜를 확인합니다.
- 글을 눌러 상세 내용을 읽습니다.
- 로그인 후 큐티나 편지를 한 건 저장합니다.
- 휴대폰 크기에서 읽기 편한지 확인합니다.

## Codex 작업 결과

예시 관리자 워크시트를 기준으로 프로젝트를 `우리 가족 말씀편지`로 바꿨습니다. 공개 목록은 글의 앞부분을 보여주고, 글을 선택하면 새 상세 화면에서 전체 묵상이나 편지를 읽을 수 있습니다. 로그인·Supabase 저장 흐름은 유지하고 관리자 화면의 문구를 묵상과 편지 작성에 맞게 변경했습니다.

## 남아 있는 문제

기존 Supabase 테스트 데이터는 수정하지 않아 현재 로컬 화면에는 영어 예시 글이 보입니다. 실제 수업에서는 로그인 후 워크시트에 적은 큐티 또는 편지를 첫 글로 저장해 확인해야 합니다.
