# 오늘의 주문서

- 주문 제목: 내 묵상에도 댓글 작성 허용
- 날짜: 2026-08-12
- 작업 상태: 완료

## 오늘 만들 기능

로그인한 사용자가 다른 사람의 묵상뿐 아니라 본인의 묵상에도 일반 댓글을 작성할 수 있게 합니다.

## 작업하는 이유

현재 화면과 RLS 정책이 본인 묵상에 대한 일반 댓글을 막고 있어, 묵상 작성자가 자신의 글에 덧붙이는 댓글을 남길 수 없기 때문입니다.

## 구체적인 요청

- 모든 로그인 사용자가 조회 가능한 QT 묵상에 최상위 댓글을 작성할 수 있게 합니다.
- 본인 묵상 상세에도 댓글 입력창을 표시합니다.
- 기존처럼 묵상 작성자는 다른 사용자가 남긴 댓글에 한 단계 작성자 답글을 남길 수 있습니다.
- 본인이 쓴 댓글에 다시 작성자 답글을 다는 동작은 추가하지 않습니다.

## 이번에는 하지 않을 작업

- 댓글과 답글 수정·삭제
- 답글에 대한 추가 답글
- 댓글 알림

## 완료 조건

- 로그인한 사용자가 본인 묵상에 일반 댓글을 저장할 수 있습니다.
- 다른 사람의 묵상 댓글 작성과 기존 작성자 답글이 유지됩니다.
- 본인이 작성한 최상위 댓글에는 작성자 답글 버튼이 나타나지 않습니다.
- RLS가 댓글 작성자 ID 위조를 막습니다.
- lint와 build가 통과합니다.

## 작업 후 사용자가 확인할 내용

- 새 migration을 Supabase SQL Editor에서 실행합니다.
- 내 묵상 상세에서 댓글을 작성하고 새로고침 후 다시 보이는지 확인합니다.
- 다른 사용자의 댓글에는 기존처럼 작성자 답글을 남길 수 있는지 확인합니다.

## Codex 작업 결과

- 본인 묵상과 다른 사용자의 묵상 모두에 일반 댓글 입력창을 표시하도록 변경했습니다.
- 본인 묵상 여부를 검사해 댓글 제출을 막던 클라이언트 조건을 제거했습니다.
- 모든 로그인 사용자가 조회 가능한 QT 묵상에 최상위 댓글을 추가할 수 있도록 RLS 정책 migration을 작성했습니다.
- 댓글의 `author_id`는 계속 로그인 사용자 ID와 일치해야 합니다.
- 묵상 작성자가 본인이 직접 쓴 댓글에는 작성자 답글을 달지 않도록 답글 버튼을 숨겼습니다.
- 기존에 다른 사용자가 남긴 댓글에 한 단계 작성자 답글을 남기는 동작은 유지했습니다.
