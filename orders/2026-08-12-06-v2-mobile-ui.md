# 오늘의 주문서

- 주문 제목: v2 모바일 UI와 가족 진행 현황 개선
- 날짜: 2026-08-12
- 작업 상태: 완료

## 오늘 만들 기능

v1을 그대로 보존하면서 v2의 글자 크기, 모바일 레이아웃, 프로필 영역과 FAMILY PROGRESS를 개선합니다.

## 작업하는 이유

현재 제목과 여백이 모바일 화면에서 지나치게 크고, 프로필과 로그아웃이 한 버튼에 섞여 있으며, 가족 진행 현황이 가로로 너무 길어 사용하기 어렵기 때문입니다.

## 구체적인 요청

- v2의 제목과 주요 글자 크기를 줄입니다.
- 입력 화면의 큰 빈 공간을 줄이고 모바일에서 위에서부터 자연스럽게 읽히게 합니다.
- 프로필 이름과 로그아웃 동작을 시각적으로 분리합니다.
- 프로필에 이름 첫 글자 아바타와 짧은 안내를 표시합니다.
- FAMILY PROGRESS의 가로 스크롤 표를 구성원별 진행 카드로 바꿉니다.
- 각 카드에 완료 수, 진행률, 진행 막대와 7열 날짜 버튼을 표시합니다.
- 완료, 오늘, 선택, 미래 날짜 상태를 구분합니다.
- 날짜 버튼을 누르는 기존 묵상 조회 동작을 유지합니다.
- 모바일 상세 모달을 화면 아래에서 올라오는 형태로 개선합니다.
- 모든 스타일 변경은 `.app-v2` 범위로 제한하고 v1은 수정하지 않습니다.
