# 프로젝트 시작 인터뷰 진행 방법

사용자가 `프로젝트 시작 워크시트를 작성할게요.`라고 말하면 이 순서를 따릅니다.

1. 앱 코드를 수정하지 않습니다.
2. `worksheets/project-start.md`와 `PROJECT_BRIEF.md`의 현재 상태를 확인합니다.
3. 종이에 작성한 답을 한꺼번에 입력해도 된다고 먼저 안내합니다.
4. 이미 여러 답을 보냈다면 아래 항목에 먼저 분류하고, 빠진 중요한 내용만 질문합니다.
5. 질문은 한 번에 하나씩 합니다. 확실히 모르는 답은 `미정` 또는 `첫 버전에서 제외`로 둘 수 있다고 안내합니다.
6. 모든 답을 모으면 정리된 초안을 채팅에 보여줍니다.
7. 사용자의 명확한 확인 전에는 파일을 수정하지 않습니다.
8. 승인 후 `worksheets/project-start.md`에 답을 저장하고 같은 내용으로 `PROJECT_BRIEF.md`를 작성하거나 갱신합니다.
9. 이 단계에서는 앱 코드를 수정하지 않습니다.
10. 문서 작성 후 다음 개발 작업 한 가지를 정할 때까지 기다립니다.

## 확인할 항목

1. 프로젝트 이름은 무엇인가요?
2. 이 프로젝트를 만들고 싶은 이유는 무엇인가요?
3. 누가 이 프로젝트를 사용하나요?
4. 공개 화면은 누가 보게 되나요?
5. 공개 화면에 무엇을 보여주고 싶나요?
6. 관리자는 어떤 내용을 입력하나요?
7. 첫 번째 버전에서 가장 중요한 기능 하나는 무엇인가요?
8. 첫 화면의 제목과 짧은 소개 문구는 무엇인가요?
9. 어떤 분위기와 주요 색상을 원하나요?
10. 참고하고 싶은 사이트나 이미지가 있나요?
11. 공개하면 안 되는 정보는 무엇인가요?
12. 바뀌어도 반드시 유지되어야 하는 기능은 무엇인가요?
13. 첫 버전에서는 무엇을 일부러 제외할까요?
14. 어떤 상태가 되면 첫 버전이 완성되었다고 볼 수 있나요?
