# 프로젝트 시작 워크시트

- 상태: 작성 완료
- 작성자 역할: 미니 권사님
- 작성 날짜: 2026-08-09

## 우리가 만들 것

- 프로젝트 이름: 우리 가족 말씀편지
- 한 문장 소개: 오늘 묵상한 말씀과 가족에게 전하고 싶은 마음을 차곡차곡 나누는 공간
- 만드는 이유: 가족 단톡방에 올린 묵상과 편지는 금방 지나가 다시 찾기 어렵습니다. 멀리 있는 가족도 같은 주소에서 천천히 읽을 수 있는 공간을 만들고 싶습니다.
- 가장 중요한 기능: 로그인한 관리자가 글을 쓰면 가족이 같은 주소에서 바로 읽을 수 있어야 합니다.

## 함께 사용할 사람

- 직접 글을 작성할 사람: 권사님 한 명
- 공개 화면을 볼 사람: 자녀, 손주, 형제자매 등 링크를 받은 가족
- 사용하는 상황: 아침 큐티 후 묵상을 남기거나 가족에게 전하고 싶은 말이 있을 때 작성합니다. 가족은 편한 시간에 휴대폰으로 읽습니다.
- 공개 범위: 주소를 받은 가족에게 공유하지만 웹에서는 로그인 없이 읽을 수 있습니다.
- 공개하지 않을 내용: 전화번호, 집 주소, 가족의 자세한 일정, 허락받지 않은 개인 사정과 민감한 기도 제목

## 화면과 내용

- 공개 목록: 글 제목, 내용의 앞부분, 작성 날짜를 최신순으로 보여줍니다.
- 상세 화면: 선택한 글의 제목, 전체 내용, 작성 날짜를 편지처럼 편안하게 보여줍니다.
- 관리 화면: 제목과 본문을 작성해 저장합니다.
- 첫 화면 제목: 오늘도 말씀 안에서, 우리 함께
- 첫 화면 소개: 묵상한 말씀과 사랑하는 가족에게 전하고 싶은 마음을 이곳에 차곡차곡 남깁니다.

## 아이디어 전체 리스트

1. 오늘의 큐티 묵상 남기기
2. 가족에게 전하는 짧은 편지 남기기
3. 최신 글부터 목록으로 보기
4. 글 하나를 선택해 편안하게 자세히 읽기
5. 휴대폰에서도 큰 글씨로 읽기
6. 가족에게 공개 URL 공유하기
7. 나중에 카테고리나 검색 추가하기

## 이번 작업 범위

### 반드시 구현

- 가족적인 제목과 소개 문구
- 제목·본문·자동 작성 날짜
- 최신순 공개 목록
- 글 상세 읽기
- 관리자 로그인과 글 저장
- 모바일 화면과 Vercel 배포 흐름 유지

### 시간이 남으면

- 빈 화면 문구를 프로젝트 분위기에 맞게 변경
- 글 카드에 편지 같은 작은 장식 추가

### 이번에는 하지 않음

- 사진과 파일 업로드
- 카테고리와 검색
- 댓글과 반응
- 알림
- 회원가입
- 수정·삭제 화면

## 디자인 방향

- 분위기: 따뜻한 편지지, 조용한 아침 묵상, 단정하고 편안한 인상
- 주요 색상: 크림색 배경, 짙은 자주색 제목, 차분한 올리브색 보조색
- 참고 이미지: 교회 주보와 손편지처럼 여백이 넉넉한 종이 화면

## 실제로 작성해볼 첫 글

### 오늘의 묵상 - 염려를 내려놓아요

오늘 말씀을 읽으며 내가 붙들고 있던 걱정을 하나님께 맡겨야겠다는 마음이 들었습니다. 우리 가족도 각자의 자리에서 염려보다 감사할 일을 하나씩 발견하는 하루가 되면 좋겠습니다.

### 사랑하는 우리 가족에게

자주 만나지 못해도 늘 마음으로 응원하고 기도하고 있어요. 바쁜 하루 중 잠깐이라도 서로를 생각하며 따뜻한 말 한마디를 나눌 수 있으면 좋겠습니다. 모두 사랑하고 축복합니다.

## 완료 기준

- 권사님이 로그인해 큐티나 편지를 저장할 수 있습니다.
- 저장한 글이 공개 목록 가장 위에 나타납니다.
- 목록에서 글을 선택하면 전체 내용을 읽을 수 있습니다.
- 가족이 휴대폰에서 공개 URL을 열어 편하게 읽을 수 있습니다.
- 사진·카테고리 없이도 목적이 분명한 첫 버전이 완성됩니다.
